# ZakyDev Phase 1 — Home Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the ZakyDev home page in `apps/web` exactly as designed: type-led hero, one gold element that transforms through five scenes, three projects, five-step process, About loop and cards, gold contact screen, in English and Arabic, dark and light, with a complete reduced-motion and no-script version.

**Architecture:** Each section is a server-rendered `<section>` with real content. After hydration a single scroll engine turns each section into a tall block with a sticky full-height scene and publishes its progress as CSS custom properties; small client components add the motion. Each scene's travel has a body (its own timeline) and a tail (the handoff); consecutive scenes overlap by one viewport so there is never a blank screen. One fixed, decorative gold element interpolates between measured slot rectangles during each tail.

**Tech Stack:** Next.js 16 App Router (RSC + small client components), React 19, Tailwind CSS 4, TypeScript 7, Web Animations API and CSS animations, one hand-written WebGL shader, Vitest 5, Playwright, axe. No animation library, no three.js. The Phase 0 plan's "Stack notes" section applies here too.

**Spec:** `docs/superpowers/specs/2026-10-13-zakydev-home-design.md`. Read all of it. Section 5 defines behaviour; section 6.4 defines structure; section 10 lists what must not be copied from the prototype.

**Prerequisite:** `docs/superpowers/plans/2026-10-13-phase-0-foundation.md` is complete on branch `rebuild/zakydev`.

**Visual reference:** `docs/prototype/home-v23/`. Run it with
`python3 -m http.server 8765 --directory docs/prototype/home-v23` and compare side by side while building. Line numbers below refer to those files.

## Global Constraints

- Work on branch `rebuild/zakydev`.
- No animation library, no three.js, no CDN or third-party runtime requests.
- Content only from `getHome(locale)` in `@zakydev/shared`; no hard-coded copy in components. Unconfirmed text renders normally (the production gate is the `REQUIRE_CONFIRMED=1` build).
- Colour, type and mark exactly as spec section 3. Gold text on light uses `--accent`.
- Logical CSS properties only (`ms-*`, `pe-*`, `inset-s-*`/`inset-e-*`; Tailwind 4.2+ deprecates `start-*`/`end-*`). All SVG drawings are forced left-to-right and never mirrored.
- Browser support: Next 16's baseline, Chrome/Edge/Firefox 111+ and Safari 16.4+. Safari still has no `requestIdleCallback`, so always fall back to `setTimeout`.
- In-page links (menu, buttons, language switch) are plain `<a>`, not `next/link`. The language switch must do a full page load, because `/en` and `/ar` are different root layouts.
- Arabic is never animated by letter and never letter-spaced.
- Every interactive thing is a real `button` or `a` with an accessible name and a visible focus ring; targets ≥ 44 px.
- Decorative drawings, the gold element, the background and the loader are `aria-hidden`.
- Content is never hidden by a state only JavaScript can remove (spec 6.5). Enhanced styles apply only under `html.enhanced`.
- Under `prefers-reduced-motion: reduce` or without JavaScript, sections are ordinary stacked blocks and every drawing shows its finished state.
- Every transition has an explicit end state, so an interrupted one still ends visible.
- Files stay under 300 lines; one component per file.
- Commit after every task with `<type>: <description>`.

## Review Focus

- **Fast back-and-forth scrolling between projects or steps:** text must end fully opaque. (Task 7 test)
- **Right-to-left with a visible scrollbar on the start side:** the gold frame must sit exactly on its slot. (Task 4 test)
- **Phone address-bar resize and orientation change mid-page:** the gold element and rail must re-align within one frame. (Task 4 test)
- **Reduced motion turned on while the page is open:** the page must switch to the stacked layout without a reload. (Task 2 test)
- **Clipboard refused (insecure context or permission):** "Copy email" must select the address instead and say nothing false. (Task 10 test)
- **Large text or a short landscape screen:** a scene whose content does not fit must flow naturally instead of clipping controls. (Task 2 test)

`apps/web/src/motion/math.ts`:
```ts
export type Rect = { x: number; y: number; w: number; h: number };

export const clamp = (v: number, lo = 0, hi = 1): number => Math.min(hi, Math.max(lo, v));
export const mix = (a: number, b: number, t: number): number => a + (b - a) * t;
export const smooth = (t: number): number => {
  const x = clamp(t);
  return x * x * (3 - 2 * x);
};
export const range = (v: number, start: number, length: number): number => smooth((v - start) / length);

export const sceneProgress = (top: number, height: number, viewport: number, tail = 0): { progress: number; body: number; out: number } => {
  const travel = height - viewport;
  if (travel <= 0) {
    const done = top < 0 ? 1 : 0;
    return { progress: done, body: done, out: done };
  }
  const scrolled = clamp(-top, 0, travel);
  const bodyTravel = Math.max(1, travel - clamp(tail, 0, travel));
  return { progress: scrolled / travel, body: clamp(scrolled / bodyTravel), out: tail > 0 ? clamp((scrolled - bodyTravel) / tail) : 0 };
};

export const stepAt = (progress: number, steps: number): { index: number; local: number } => {
  const scaled = clamp(progress) * steps;
  const index = Math.min(steps - 1, Math.floor(scaled));
  return { index, local: clamp(scaled - index) };
};

export const lerpRect = (a: Rect, b: Rect, t: number): Rect => ({ x: mix(a.x, b.x, t), y: mix(a.y, b.y, t), w: mix(a.w, b.w, t), h: mix(a.h, b.h, t) });
```

| Scene | length | tail | body travel | What happens in the tail |
|---|---|---|---|---|
| hero | 2.0 | 0.5 | 0.5 | underline grows into the project frame (the zoom itself runs over the whole travel, use `progress`) |
| work | 3.2 | 0.4 | 1.8 | frame collapses into the rail line |
| process | 2.6 | 0.3 | 1.3 | line closes into the ring |
| about | 2.15 | 0.25 | 0.9 | ring floods the screen |
| contact | 1.5 | 0 | 0.5 | — |

export const gotoScene = async (page: Page, id: string, fraction: number): Promise<void> => {
  await page.evaluate(
    ([sceneId, f]) => {
      const el = document.getElementById(sceneId as string) as HTMLElement;
      const sticky = el.querySelector('[data-sticky]') as HTMLElement;
      const viewport = sticky.clientHeight || window.innerHeight;
      const travel = Math.max(0, el.offsetHeight - viewport);
      const body = Math.max(0, travel - Number(el.dataset.tail ?? 0) * viewport);
      window.scrollTo({ top: el.offsetTop + body * (f as number), behavior: 'instant' });
    },
    [id, fraction] as const,
  );
  await page.waitForTimeout(700);
};

`apps/web/src/motion/engine.ts`:
```ts
import { sceneProgress } from './math';

export type SceneId = 'hero' | 'work' | 'process' | 'about' | 'contact';
export type SceneFrame = { id: SceneId; progress: number; body: number; out: number; top: number; end: number; viewport: number; sticky: HTMLElement };
export type ScrollInfo = { y: number; velocity: number };
type Listener = (frames: Map<SceneId, SceneFrame>, scroll: ScrollInfo) => void;

const scenes = new Map<SceneId, { section: HTMLElement; sticky: HTMLElement }>();
const listeners = new Set<Listener>();
const frames = new Map<SceneId, SceneFrame>();
let raf = 0;
let running = false;
let dirty = true;
let lastY = 0;
let velocity = 0;
const LAST: SceneId = 'contact';

/** A scene is pinned only while its content fits; otherwise it flows naturally (large text, short screens). */
const fit = (): void => {
  for (const { section, sticky } of scenes.values()) {
    section.removeAttribute('data-unpinned');
    if (sticky.scrollHeight > sticky.clientHeight + 1) section.setAttribute('data-unpinned', 'true');
  }
};

const tick = (): void => {
  raf = 0;
  if (!running) return;
  const y = window.scrollY;
  velocity += (y - lastY - velocity) * 0.2;
  lastY = y;
  for (const [id, { section, sticky }] of scenes) {
    const box = section.getBoundingClientRect();
    const viewport = sticky.clientHeight || window.innerHeight;
    const r = sceneProgress(box.top, box.height, viewport, Number(section.dataset.tail ?? 0) * viewport);
    section.style.setProperty('--p', r.body.toFixed(4));
    section.style.setProperty('--out', r.out.toFixed(4));
    section.style.setProperty('--full', r.progress.toFixed(4));
    const past = box.bottom - viewport; // > 0 while this scene still has travel left
    section.dataset.state = box.top > 0 ? 'before' : past > 0 || (id === LAST && past >= -1) ? 'active' : 'after';
    frames.set(id, { id, ...r, top: box.top + y, end: box.top + y + box.height - viewport, viewport, sticky });
  }
  for (const listener of listeners) listener(frames, { y, velocity });
  if (Math.abs(velocity) > 0.05 || dirty) {
    dirty = false;
    schedule();
  }
};
const schedule = (): void => {
  if (!raf && running) raf = requestAnimationFrame(tick);
};
const onScroll = (): void => {
  dirty = true;
  schedule();
};
const onResize = (): void => {
  fit();
  onScroll();
};
const onVisibility = (): void => {
  if (!document.hidden) onScroll();
};

export const engine = {
  register(id: SceneId, section: HTMLElement, sticky: HTMLElement): () => void {
    scenes.set(id, { section, sticky });
    onResize();
    return () => {
      scenes.delete(id);
      frames.delete(id);
    };
  },
  subscribe(listener: Listener): () => void {
    listeners.add(listener);
    onScroll();
    return () => listeners.delete(listener);
  },
  invalidate: onScroll,
  scrollToScene(id: SceneId, bodyFraction = 0.06): void {
    const scene = scenes.get(id);
    if (!scene) return;
    const viewport = scene.sticky.clientHeight || window.innerHeight;
    const travel = Math.max(0, scene.section.offsetHeight - viewport);
    const body = Math.max(0, travel - Number(scene.section.dataset.tail ?? 0) * viewport);
    window.scrollTo({ top: scene.section.offsetTop + body * bodyFraction, behavior: 'smooth' });
  },
  start(): void {
    if (running) return;
    running = true;
    lastY = window.scrollY;
    window.addEventListener('scroll', onScroll, { passive: true });
    window.addEventListener('resize', onResize);
    document.addEventListener('visibilitychange', onVisibility);
    document.fonts?.ready.then(onResize).catch(() => undefined);
    onResize();
  },
  stop(): void {
    running = false;
    if (raf) cancelAnimationFrame(raf);
    raf = 0;
    window.removeEventListener('scroll', onScroll);
    window.removeEventListener('resize', onResize);
    document.removeEventListener('visibilitychange', onVisibility);
    for (const { section } of scenes.values()) {
      for (const name of ['--p', '--out', '--full']) section.style.removeProperty(name);
      section.removeAttribute('data-state');
      section.removeAttribute('data-unpinned');
    }
  },
};
```

The `data-state` rule in plain words: `before` until the section's top reaches the viewport top; `active` while it still has travel left (the last scene stays active at the very bottom of the page); `after` once the next scene has taken over. Because consecutive scenes overlap by one viewport, exactly one scene is active at every scroll position, and a test checks that. The viewport height is always the sticky element's own height, never `window.innerHeight`, so mobile browser chrome cannot desynchronise CSS (`svh`) and script.

import { type SceneId, engine } from './engine';

const IDS: SceneId[] = ['hero', 'work', 'process', 'about', 'contact'];

/** Turns enhanced mode on after hydration and off whenever the visitor asks for reduced motion. */
export function EngineProvider({ children }: { children: ReactNode }) {
  useEffect(() => {
    const query = window.matchMedia('(prefers-reduced-motion: reduce)');
    const fromHash = (): void => {
      const id = window.location.hash.slice(1) as SceneId;
      if (IDS.includes(id)) engine.scrollToScene(id);
    };
    const apply = (): void => {
      const on = !query.matches;
      document.documentElement.classList.toggle('enhanced', on);
      if (on) {
        engine.start();
        document.dispatchEvent(new Event('zk:enhanced'));
        requestAnimationFrame(fromHash);
      } else engine.stop();
    };
    // keyboard focus must never land on a scene that is faded out
    const onFocus = (event: FocusEvent): void => {
      const section = (event.target as HTMLElement | null)?.closest<HTMLElement>('[data-scene]');
      if (section && section.dataset.state !== 'active' && document.documentElement.classList.contains('enhanced')) engine.scrollToScene(section.id as SceneId, 0.3);
    };
    apply();
    query.addEventListener('change', apply);
    window.addEventListener('hashchange', fromHash);
    document.addEventListener('focusin', onFocus);
    return () => {
      query.removeEventListener('change', apply);
      window.removeEventListener('hashchange', fromHash);
      document.removeEventListener('focusin', onFocus);
      engine.stop();
      document.documentElement.classList.remove('enhanced');
    };
  }, []);
  return <>{children}</>;
}

```ts
export type TyperState = { index: number; shown: number; phase: 'typing' | 'holding' | 'deleting' | 'waiting' };
export const initialTyper: TyperState = { index: 0, shown: 0, phase: 'typing' };

const TYPE_MS = 64;
const HOLD_MS = 3000;
const DELETE_MS = 26;
const WAIT_MS = 380;

export const textOf = (state: TyperState, texts: string[]): string => (texts[state.index] ?? '').slice(0, state.shown);

/** One tick of the title animation. `delay` is how long to wait before the next tick. */
export const stepTyper = (state: TyperState, texts: string[]): { state: TyperState; delay: number } => {
  const full = (texts[state.index] ?? '').length;
  if (texts.length === 0) return { state, delay: HOLD_MS };
  if (state.phase === 'typing') {
    const shown = Math.min(full, state.shown + 1);
    return shown >= full ? { state: { ...state, shown, phase: 'holding' }, delay: HOLD_MS } : { state: { ...state, shown }, delay: TYPE_MS };
  }
  if (state.phase === 'holding') return { state: { ...state, phase: 'deleting' }, delay: DELETE_MS };
  if (state.phase === 'deleting') {
    const shown = state.shown - 1;
    return shown <= 0 ? { state: { ...state, shown: 0, phase: 'waiting' }, delay: WAIT_MS } : { state: { ...state, shown }, delay: DELETE_MS };
  }
  return { state: { index: (state.index + 1) % texts.length, shown: 1, phase: full === 0 ? 'waiting' : 'typing' }, delay: TYPE_MS };
};
```

'use client';

import { useEffect, useRef, useState } from 'react';

const OUT = 180;
const IN = 500;
const EASE = 'cubic-bezier(.2,.8,.2,1)';

/** Text that flips to a new value. Its resting style is always fully visible. */
export function Swap({ value, className }: { value: string; className?: string }) {
  const [shown, setShown] = useState(value);
  const node = useRef<HTMLSpanElement>(null);
  useEffect(() => {
    if (value === shown) return;
    const el = node.current;
    const still = !el || window.matchMedia('(prefers-reduced-motion: reduce)').matches || !el.animate;
    if (still) {
      setShown(value);
      return;
    }
    for (const running of el.getAnimations()) running.cancel();
    const out = el.animate([{ transform: 'none', opacity: 1 }, { transform: 'rotateX(-80deg) translateY(-35%)', opacity: 0 }], { duration: OUT, easing: 'ease-in', fill: 'none' });
    let cancelled = false;
    out.finished
      .then(() => {
        if (cancelled) return;
        setShown(value);
        el.animate([{ transform: 'rotateX(80deg) translateY(35%)', opacity: 0 }, { transform: 'none', opacity: 1 }], { duration: IN, easing: EASE, fill: 'none' });
      })
      .catch(() => setShown(value));
    return () => {
      cancelled = true;
      out.cancel();
    };
  }, [value, shown]);
  return (
    <span ref={node} className={className} style={{ display: 'inline-block', transformOrigin: '50% 60%' }}>
      {shown}
    </span>
  );
}

```ts
import type { SceneFrame, SceneId } from './engine';
import { type Rect, lerpRect, mix, smooth } from './math';

export type GoldShape = Rect & { radius: number; fill: number; round: number };
type Reader = (frame: SceneFrame, layer: HTMLElement) => GoldShape;

const slots = new Map<SceneId, Reader>();

export const registerSlot = (scene: SceneId, read: Reader): (() => void) => {
  slots.set(scene, read);
  return () => {
    if (slots.get(scene) === read) slots.delete(scene);
  };
};

export const readSlot = (layer: HTMLElement) => (id: SceneId, frame: SceneFrame): GoldShape | null => slots.get(id)?.(frame, layer) ?? null;

/**
 * Where a slot sits on screen once its scene is pinned, in the gold layer's coordinates.
 * x is measured against the layer itself, so a scrollbar on the start side or any other
 * shift of the page cannot offset it. y is measured against the slot's own sticky scene.
 */
export const pinnedRect = (slot: HTMLElement, sticky: HTMLElement, layer: HTMLElement): Rect => {
  const a = slot.getBoundingClientRect();
  const s = sticky.getBoundingClientRect();
  const l = layer.getBoundingClientRect();
  return { x: a.left - l.left, y: a.top - s.top, w: a.width, h: a.height };
};

export const resolveGold = (order: SceneId[], frames: Map<SceneId, SceneFrame>, scrollY: number, read: (id: SceneId, frame: SceneFrame) => GoldShape | null): GoldShape | null => {
  const present = order.filter((id) => frames.has(id));
  let at = -1;
  present.forEach((id, i) => {
    if ((frames.get(id) as SceneFrame).top <= scrollY + 1) at = i;
  });
  if (at < 0) at = 0;
  const currentId = present[at];
  if (!currentId) return null;
  const currentFrame = frames.get(currentId) as SceneFrame;
  const current = read(currentId, currentFrame);
  const nextId = present[at + 1];
  const next = nextId ? read(nextId, frames.get(nextId) as SceneFrame) : null;
  if (!current) return next;
  const t = smooth(currentFrame.out);
  if (!next || t <= 0) return current;
  if (t >= 1) return next;
  return { ...lerpRect(current, next, t), radius: mix(current.radius, next.radius, t), fill: mix(current.fill, next.fill, t), round: mix(current.round, next.round, t) };
};
```

import { useEffect, useRef } from 'react';
import { type SceneId, engine } from './engine';
import { readSlot, resolveGold } from './gold';

const ORDER: SceneId[] = ['hero', 'work', 'process', 'about', 'contact'];

export function GoldElement() {
  const layer = useRef<HTMLDivElement>(null);
  const node = useRef<HTMLDivElement>(null);
  useEffect(
    () =>
      engine.subscribe((frames, scroll) => {
        const el = node.current;
        if (!el || !layer.current) return;
        const shape = resolveGold(ORDER, frames, scroll.y, readSlot(layer.current));
        if (!shape || shape.w < 2) {
          el.style.visibility = 'hidden';
          return;
        }
        el.style.visibility = 'visible';
        el.style.transform = `translate3d(${shape.x}px, ${shape.y}px, 0)`;
        el.style.width = `${shape.w}px`;
        el.style.height = `${Math.max(3, shape.h)}px`;
        el.style.borderRadius = `${shape.radius + shape.round * Math.min(shape.w, shape.h) * 0.5}px`;
        el.style.setProperty('--fill', shape.fill.toFixed(3));
        el.dataset.thin = shape.h < 12 ? 'true' : 'false';
      }),
    [],
  );
  return (
    <div ref={layer} data-gold-layer aria-hidden="true">
      <div ref={node} data-gold>
        <div id="gold-content" />
      </div>
    </div>
  );
